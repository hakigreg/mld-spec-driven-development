# GitHub repositories to inspect

These repository URLs were opened and checked on 2026-11-24. They illustrate
possible tools and specification formats; none is a dependency of this Lab.

- [github/spec-kit](https://github.com/github/spec-kit) is the official
  Spec Kit project. Inspect `spec-driven.md`, `templates/`, and its
  quickstart to see how it separates requirements, planning, tasks, and
  implementation. Its generated workflow is broader than this Lab's manual
  three-document example.
- [cucumber/gherkin](https://github.com/cucumber/gherkin) maintains the
  Gherkin parser and compiler. Inspect its examples and language grammar to
  see how plain-language scenarios can become structured, executable
  specifications. This Lab deliberately uses ordinary Markdown instead.
- [OAI/OpenAPI-Specification](https://github.com/OAI/OpenAPI-Specification)
  maintains the OpenAPI standard. Inspect the specification and examples to
  understand how interface contracts can be machine-readable. An API
  contract is useful for service boundaries but does not replace the full
  feature intent in a human-reviewed spec.
